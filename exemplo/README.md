# Dados de exemplo (fictícios)

Tudo aqui é inventado: a **Lumi Tecnologia**, a cidade de **Vila Serena (PR)**, os clientes, os leads, os telefones
(DDD 00, que não existe) e os números. Serve para conhecer o Ciello OS antes de colocar os seus dados.

Na primeira vez que o Ciello OS abre, esta pasta é copiada para os lugares de verdade (comercial/, financeiro/,
roteiros/...) e a lista do que foi copiado fica em `estado/dados.json`. Depois, na janela **Boas-vindas**:

- **Limpar dados de exemplo** apaga só o que veio daqui (o que você editou fica, com aviso).
- **Importar meus dados** recebe um `.zip` exportado do Ciello OS (ou montado à mão com as mesmas pastas).

Pela linha de comando: `python central/dados_iniciais.py status | exemplo | limpar | importar arquivo.zip | exportar arquivo.zip`.
